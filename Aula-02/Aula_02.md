C4 - Contexto, Conteiner, Componente, Codigo

Contexto - é uma aplicação como se fosse um container ou repositório, uma caixa só de atores e vizinhos
Conteiner - É como a estrutura do projeto é dividida (BackEnd, FrontEnd, Bando de Dados)
Componente - São as classes do seu projeto
